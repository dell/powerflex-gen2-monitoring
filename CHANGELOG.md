# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-05-04

### Added
- Initial open source release
- PowerFlex Gen2 metrics collection via REST API v5 (siocli.py, sio_sdk)
- InfluxDB line protocol output for Telegraf integration
- 8 pre-built Grafana dashboards (Cluster, Devices, Pools, SDC_Hosts, Storage Node, Volumes, Capacity)
- Example configurations for Telegraf, InfluxDB, and Grafana
- Unit tests for SDK, CLI, and metrics tagging
- Apache License 2.0
- SECURITY.md, CONTRIBUTING.md, CODE_OF_CONDUCT.md
